Créez vos contenus pour les écrans LFC, prévisualisez-les, diffusez-les et programmez leurs horaires depuis Mac ou Windows.

Vous pouvez télécharger ces fichiers **sans compte GitHub**. Ce site héberge simplement les téléchargements et les guides du Studio.

### Si vous ouvrez la liste des versions

1. Ouvrez **[Toutes les versions](https://github.com/WITH-BY/lfc-studio-releases/releases)**.
2. Choisissez une version qui propose votre système. Le mot **Pre-release** indique une préversion à essayer ; certaines versions ne contiennent qu’un paquet Mac.
3. Cliquez sur **Assets** pour afficher les fichiers.
4. Sur Mac, ouvrez le **.dmg** correspondant à votre processeur. Sur Windows, ouvrez **x64-setup.exe**.

Les liens **Source code**, les archives **.app.tar.gz**, les signatures **.sig** et les empreintes **SHA256SUMS** sont destinés au développement ou à la mise à jour : vous n’en avez pas besoin pour installer l’application manuellement.

## Démarrer avec votre premier appareil

Le [guide des premiers pas](docs/PREMIERS-PAS.md) explique chaque étape : rejoindre le Wi-Fi du Tube, lui donner un nom, créer un nouveau mot de passe de secours, ajouter le réseau du lieu et lancer la visite guidée.

Exemple : un appareil nommé **Salon** crée le réseau **LFC-Salon**. Le Studio conserve ses identifiants de secours sur votre ordinateur. La connexion directe peut afficher **« Pas d’Internet »** : elle sert à parler à l’appareil.

Vous pouvez ensuite découvrir le logiciel avec des appareils fictifs en mode démo. À la sortie de la visite, vous retrouvez vos appareils et créations réels.

## Besoin d’aide ?

Dans l’application : **Réglages → Nous écrire**. Sur ce site : **[Questions et retours](https://github.com/WITH-BY/lfc-studio-releases/issues)** ; un compte GitHub est nécessaire pour y écrire.

Indiquez la version du Studio, Mac ou Windows, ce que vous essayiez de faire et le message affiché. Ne publiez pas de mot de passe Wi-Fi ou de code de protection.

## À propos de cette préversion

Les notes de chaque version précisent les fonctions et les essais réalisés. Les paquets sans signature système peuvent demander une autorisation à l’ouverture, expliquée dans les guides. Le Live réel reste désactivé pendant sa qualification. Le build d’un installateur ne constitue pas un test du Wi-Fi ou des LED sur votre appareil.
